Physical-device limitation
--------------------------
The sandbox cannot prove the location returned by a real iPhone or Windows
machine. The implementation uses the browser Geolocation API and moves the pin
as soon as the browser/OS reports a valid position, then refines the marker and
accuracy circle if a better fix arrives. Actual precision/availability depends
on OS/browser permission, Location Services, hardware (GPS where present), and
available Wi-Fi/cellular/network location signals.
