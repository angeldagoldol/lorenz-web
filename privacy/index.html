Privacy

Privacy Notice

This notice is based on the data flows implemented in the supplied Dagoldol code. It avoids claiming retention periods or legal bases that are not defined in the application source.

Data used by the application

  • Authentication data handled through Supabase Auth, including account email and password credentials.
  • Profile data such as display name, full name, contact email, phone, biography, and optional avatar.
  • Saved delivery information including name, phone, street address, city, postal code, and landmark.
  • Order information including items, quantities, prices recorded with the order, delivery fee, promotion, total, payment method, payment reference, optional payment proof, status, and rating state.
  • Contact-form messages and direct-message content, thread metadata, reactions, typing/presence state, and unread status.
  • Administrative activity records created by the application for events such as signup and login.

Browser storage

  • localStorage: guest cart data and a geocoding cache used to avoid repeatedly looking up the same address.
  • sessionStorage: the Phase 3 checkout draft, so item selections can survive navigation or a refresh within the same browser tab.

External services

Dagoldol uses Supabase for authentication, database access, Realtime features, Edge Functions, and file storage. Address lookup is sent to OpenStreetMap Nominatim and route-distance lookup is sent to the public OSRM routing service when delivery is calculated.

Payment-proof privacy

Under the Phase 3 storage migration, new payment screenshots are stored in a private payment-proofs bucket. The customer who owns the top-level storage folder and authorized administrators can receive time-limited signed access. The migration normalizes legacy Supabase public payment-proof URLs that match the earlier Dagoldol upload path; any nonmatching legacy records still require manual review.

Retention and deletion

The supplied application does not define a complete retention schedule for every record type. Customers can edit profile information through the app, and administrators have account-management tools. For access, correction, or deletion requests that are not available in the interface, contact Dagoldol. Some order or transaction information may need to be retained where required for legitimate business or legal obligations.
