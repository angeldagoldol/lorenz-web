Orders

Returns & Cancellations

Dagoldol currently provides an in-app cancellation control for early order stages but does not yet provide an automated return or refund portal.

Order cancellation

A customer can cancel an order while its persisted status is Order Placed or Processing. Once the order is Shipped or later, the application no longer offers customer cancellation.

Returns after shipment

There is no automated return request, return-label, or refund workflow in the current application. Contact Dagoldol before sending an item back so the specific order, item condition, reason, and available remedy can be reviewed.

Payment and refund records

Keep the order number, payment reference, and any relevant photos. The application stores payment references and can store a payment screenshot with the order. Phase 3 configures new payment-proof uploads as private storage objects.

Applicable rights

This page describes the current site workflow. It does not remove or limit rights that apply under mandatory consumer law.
